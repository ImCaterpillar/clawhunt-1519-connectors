# 实现说明 — #1519 飞书与 WPS 连接器

## 需求还原

企业知识库与多 Agent 协作系统（系列 50 单）的拆单之一。本单范围：
**飞书文档同步（分页拉取、增量识别）+ WPS 同步（同上接口抽象）+
权限映射与失败处理示例**。

验收标准：**提交配置、分页同步及权限失败处理示例**。

## 设计

### 1. 统一连接器抽象

`BaseConnector` 定义 `sync/state/save_state/load_state` 四个方法；
飞书/WPS 各自继承并只实现 `_page(idx)`（数据源分页）。新增平台
（钉钉/Notion 等）只需加一个子类。

### 2. 分页同步 + 断点续传

- `cursor` 游标：**每页完整处理完才推进**——中途失败可从断点恢复，
  不重复不丢失（测试 5）；
- `synced[doc_id]` 幂等去重：重复同步零新增（测试 4）；
- `save_state/load_state` 状态可持久化。

### 3. 权限失败处理（验收核心）

无权限文档（模拟 403）**跳过并写审计**（`permission_denied_skip`，
含 doc_id/标题/action），**不中断整个同步**——这是真实企业环境的
必须行为：一个敏感文档无权限不应卡死全库同步。飞书样例 2 条被跳过、
6 条正常入库（测试 2）。

### 4. 零依赖 + 模拟数据源

纯标准库；模拟数据源（3 页×3-4 条，含 2 条无权限）验证逻辑，
真实 API 接入留 adapter（继承改 `_page` 即可）。
